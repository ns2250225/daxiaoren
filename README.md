# 像素打小人

一个纯前端的像素风解压小游戏：扮演驱邪师，用风刃、枪械、法术乃至拖鞋狂揍屏幕里的"小人"，打出华丽连击，攒满奥义能量后释放全屏演出的大招！

> 零依赖、零构建、零后端 —— 克隆下来双击 `index.html` 就能玩。

## ✨ 特性

- 🎮 **6 种常规技能**：风刃斩、速射枪、爆炎球、九天落雷、冰棘突刺、拖鞋神功，按住可连发，多键可同时按
- 💥 **3 种全屏奥义**：千雷万剑、陨星天降、虚空湮灭，每种都有专属的过场演出、台词与终结画面
- 🔢 **连击系统**：连续命中累计连击数，伤害数字为手绘 3×5 像素字体
- 🔊 **实时合成音效**：全部音效由 Web Audio API 实时合成，不含任何音频文件
- 🖼️ **纯代码像素美术**：角色、背景、特效全部由代码在 480×270 的低分辨率画布上绘制，3 倍放大保持像素锐利
- 📱 **三端自适应**：桌面端横屏布局 / 手机竖屏布局 / 手机平板横屏布局，触屏按钮支持多指同时按住连发
- ⚡ **打击感细节**：hit stop 卡帧、屏幕震动、受击白闪、血条延迟白条（ghost bar）一应俱全
- ✏️ **自定义小人名字**：给挨打的小人起个名字，"打小人"更有针对性 😄

## 🚀 快速开始

无需安装任何依赖，任选其一：

```bash
# 方式一：直接用浏览器打开
start index.html        # Windows
open index.html         # macOS

# 方式二：起个本地静态服务器（推荐，体验更佳）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 🕹️ 操作说明

### 桌面端（键盘）

| 按键 | 技能 | 说明 |
| --- | --- | --- |
| `J` | 风刃斩 | 挥出风刃，命中后触发斩击特效 |
| `K` | 速射枪 | 高射速连发 |
| `L` | 爆炎球 | 投射爆炎球，范围爆炸 |
| `U` | 九天落雷 | 天降落雷劈中小人 |
| `I` | 冰棘突刺 | 地面冰棘突刺而出 |
| `O` | 拖鞋神功 | 掷出旋转拖鞋（物理飞行） |
| `空格` | 千雷万剑（奥义） | 消耗满槽奥义能量 |
| `Q` | 陨星天降（奥义） | 消耗满槽奥义能量 |
| `E` | 虚空湮灭（奥义） | 消耗满槽奥义能量 |
| `M` | 静音开关 | 切换音效 |

- 按住技能键可自动连发；多个技能键可同时按住
- 普通技能命中会积攒奥义能量，能量满 100 后释放奥义
- 也可以直接鼠标点击 / 按住屏幕下方的技能按钮施放

### 移动端（触屏）

- 点击或按住技能按钮即可施放，按住可连发，支持多指同时操作
- 竖屏与横屏各有一套专属布局，按钮位置随屏幕方向自动切换

## 🛠️ 技术要点

- **双画布架构**：游戏逻辑运行在 480×270 的离屏"世界画布"上，每帧按 3 倍放大绘制到 1440×810 的屏幕画布，配合 `image-rendering: pixelated` 保持像素风格
- **程序化像素精灵**：角色用字符画矩阵 + 调色板定义，运行时生成精灵画布，改色只需改字符
- **Web Audio 合成音效**：刀光、枪声、爆炸、雷击等音效全部用振荡器 + 噪声实时合成，无外部资源
- **脚本化奥义演出**：大招按实时时间轴驱动，包含暗幕、聚光、演出台词、终结一击等阶段，演出期间 UI 自动隐藏
- **无任何第三方依赖**：不依赖框架、打包器或图片音频资源
